AI Studio Turn Trimmer 2.1.0

Purpose
Trim Google AI Studio conversations by keeping a chosen turn, deleting older or newer turns, or deleting until the displayed token count reaches a target.

Safety
Deletion starts only after an explicit user action. The selected turn is preserved when using Trim Up or Trim Down. The extension verifies progress after each operation and stores resumable job state locally.

Data
No data is collected or transmitted. All settings and progress remain in browser extension storage.
